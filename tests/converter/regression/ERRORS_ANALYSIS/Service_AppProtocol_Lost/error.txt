- Impact is real, not cosmetic: Istio (and other meshes) use appProtocol to select the correct L7 protocol handler. Losing appProtocol: grpc means the port is treated as plain TCP, breaking gRPC-aware routing, retries and telemetry.
- Grouped with sessionAffinity and externalTrafficPolicy in the report as a family of Service spec fields the conversion drops (see Service_SessionAffinity_Lost and Service_ExternalTrafficPolicy_Lost) — same file, likely the same one-line fix per field.
- Concrete affected object named in the report: Service/observability-otel-collector, port otlp-grpc.
- Fix: capture spec.ports[*].appProtocol in build_service_entry and render it in service.yaml.
